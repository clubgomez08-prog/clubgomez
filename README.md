# Club Gómez

Landing y sistema de membresías **Club Gómez**.

**Demo:** [https://club-gomez.vercel.app](https://club-gomez.vercel.app)

## Stack

- Next.js (App Router)
- Supabase
- Resend (emails)
- Pasarela de pagos: por definir (Wompi / Bold / Mercado Pago)

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Rutas principales

| Ruta | Descripción |
|------|-------------|
| `/` | Homepage Club Gómez |
| `/beneficios` | Catálogo de premios |
| `/formulario?plan=` | Registro / membresía |
| `/admin-mockup` | Dashboard demo |
| `/admin` | Panel Club Gómez (solicitudes, fechas Motilón, dashboard) |
